# Project instructions

Follow the repository guidelines in [AGENTS.md](AGENTS.md).

For frontend screens, always use the existing system components from `ai-front-end-imobiliaria/src/components/ui` and `ai-front-end-imobiliaria/src/components/layout`. Check for standard buttons, inputs, date pickers, cards, tables and pagination before building UI, and extend shared components when needed instead of recreating them with raw elements or ad hoc styling.
