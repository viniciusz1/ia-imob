# Evidências — flags Novo e Oportunidade

Estas imagens registram a entrega de 24/09/2026 na tela voltada ao cliente.

- `novidades.png`: filtro **Novidades**, com anúncios classificados como **Novo**.
- `oportunidades.png`: filtro **Oportunidades**, com o selo e o score de custo-benefício.

As classificações são calculadas no backend a partir do último snapshot publicado de cada imobiliária. Um anúncio é **Novo** quando sua identidade estável não aparece nos snapshots publicados da mesma imobiliária nos 30 dias anteriores. Um anúncio é uma **Oportunidade** quando há pelo menos cinco imóveis comparáveis e seu preço por metro quadrado está pelo menos 15% abaixo da mediana desses comparáveis.

As duas flags são independentes: o mesmo anúncio pode receber ambas.
